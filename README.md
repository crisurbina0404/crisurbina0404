## 🧠 Sobre mí

Estudiante de Ingeniería en Sistemas de Información con una convicción: **el buen software se escribe entendiendo la máquina que lo ejecuta y el proceso que lo necesita**. Por eso combino programación, bases de datos y una curiosidad seria por el hardware.

Estoy en etapa de prototipado: construyo versiones funcionales, las pruebo, las rompo y las mejoro. Cada repositorio es un laboratorio de aprendizaje deliberado.

| `componente` | `especificación` |
| :-- | :-- |
| 🏗️ **Arquitectura** | Ingeniería en Sistemas de Información — en curso |
| 🧠 **Procesador** | Python — lógica, scripting y automatización |
| 💾 **Memoria** | SQL — modelado relacional y consultas |
| 🖥️ **Interfaz** | HTML · CSS · JavaScript |
| 🔧 **Overclock** | Hardware: ensamblaje, diagnóstico y benchmarks |
| 🏢 **Procesos** | Sistemas empresariales (ERP) y flujos de negocio reales |
| 🔄 **Firmware** | Aprendizaje continuo — iterar, medir, mejorar |
| ⚽ **Modo reposo** | Fútbol y exploración de nuevas tecnologías |
